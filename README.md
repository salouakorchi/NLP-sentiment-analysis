# 🧠 Financial Sentiment Analysis with FinBERT

Projet d’analyse de sentiments financiers utilisant le **NLP**, le **Machine Learning** et les **Transformers**.

Le projet compare trois approches :

- Logistic Regression
- Bidirectional LSTM
- FinBERT fine-tuné

## 🎯 Objectif

Classifier automatiquement les phrases financières en trois catégories :

- 🔴 Negative
- ⚪ Neutral
- 🟢 Positive
